# read-email 用法

- read-email_new：从旧到新编号成「=== 邮件 N ===」，同一次运行里编号不变。开头写着「后面的用 first=… 再取」就接着取，直到取完。
- read-email_find：找某封、某类邮件里的事实时用。

逐封作答（主模型要你把新邮件逐封过一遍时）：
- 主模型写了范围（如「第 1–15 封」）就只读这几封（first、count 照填），读完交回；没写范围就全部取完再交回。
- 每个问题对每一封都答一遍：question 照抄主模型的问题，item 写邮件编号 N（「=== 邮件 N ===」的 N）。
- 只问一次的问题（如时间范围、这批共几封）答一条，不写 item；「共几封」的 quote 抄写着「这批共 N 封」的那一行。
- 一封里有几个答案（如几个日期）就写几条，question、item 相同。
- quote 从这封邮件逐字复制：标题抄 Subject 行，发件人抄 From 行，日期抄 Date 行；要做什么抄原文提出要求的那一句，
  没要求收件人做事（通知、收据、确认、广告、newsletter）就答「无」、quote 抄 Subject 行。答案里的数字要出现在 quote 里。
- 只照原文答（金额、地点、时间照原文），不判断、分类或建议；模板、横幅、页脚、旧公告里与这封无关的不算。
- 这封没有答案：answer、quote、source 写 null，照样写 item。不转发全文，不引用链接。
- 取到的每一封都算读过，都要作答。
