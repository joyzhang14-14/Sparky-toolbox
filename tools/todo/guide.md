# todo 用法

什么时候建：事情要好几步才做完，或者你答应了之后要做的事（「渲完再回测」「明天提醒」），就用 todo_create 记下来。一两步就完的不用建。
待办只列要用工具做的事；最后回复里的汇总、说明不用列成一项（回复写完就打不了勾了）。

- todo_create(items)：新建一份清单，每项一句话，返回带编号的清单。
- todo_add(items)：做的过程中发现还要做的，加进去。
- todo_done(item, evidence)：做完一项就打勾。item 写编号或原文；evidence 写一句依据，只写这次工具结果里看得到的（测出的数、生成的文件路径、命令的输出）。没真做过、没有结果的不要打勾。
- todo_drop(item, reason)：不做了、做不了，就放弃并写原因，会告诉 Joy。不要为了清掉清单假装做完。

没清掉的跨运行保留，下次运行开头会再列给你；留到以后做的不动它，在回复里说清楚。
