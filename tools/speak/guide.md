# speak 用法

- text：要念的中文，长度不限。长文整篇放进一次调用，工具自己按句子切块、念完拼成一条录音；不要自己拆成几次调用（会变成好几条录音）。只念中文和英文，日文念不了；夹英文词、数字、单位没问题（「87%」会念成「百分之八十七」）。
- mood：整篇的语气，长文也有效。写 平静（默认）/ 开心 / 害羞 / 生气 / 难过 / 温柔 之一，或者用一句话描述想要的语气，比如「压低声音说悄悄话」「哭着说，一边抽泣」「刚睡醒，迷迷糊糊打着哈欠」「模仿一位慈祥的老奶奶」。
- segments：一篇里要换好几种语气时用，写成 [{text, mood}, …]，每段一个语气，按顺序念完拼成一条录音。用了 segments 就不写 text 和 mood。
- 声音标记：text 里可以写 [笑] [叹气] [咳嗽] [清嗓子]，会发出对应的声音，不会念成字。
- 圆括号里的舞台说明（如「（笑）」）和表情符号会先去掉，不念；去掉了东西时，返回里有 spoken_text（实际念的文字）。想要笑声用 [笑]。
- 能哼唱：mood 写「轻轻地哼唱出来，像唱摇篮曲一样有旋律」这类描述，text 写要唱的词，会带着旋律唱出来（只试过一句短的歌词）。
- 别单独念一个字（「嗯。」这种不可靠），写成一小句（「嗯，好的。」）。
- timeout 可选，默认 30 分钟，念很长的文字写大一点。
- 返回 JSON：file（ogg 录音，用 reply 的 files 发给 Joy）、wav_file（无损原件）、duration_s、chunks（分了几块）、redone_chunks（停顿检查不过、重念过的块）、pause_issues（重念后还剩的停顿问题，只供参考）。
- disk、reason 平常不写。
