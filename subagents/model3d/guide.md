# model3d 用法

- 图写工作目录下的绝对路径：Joy 私信发来的在 in/（消息里有路径），之前生成的在 media/。
- 只有文字时先用 image 子代理画一张：单个物体、完整入画、正面略带俯视、纯色背景、光线均匀；看过预览再交给 model3d。
- 多角度：left / back / right 是同一物体、同样大小和光线的侧面与背面，三张不必都给；用 image 改图出侧面时以正面图为参考。
- 左右按画面里的朝向分：left 是物体朝画面左边的那张，right 是朝画面右边的那张；转身图（正面、侧面、背面、侧面）别按顺序填，接反了背面会长出脸、出现重影。
- prompt 写这是什么物体（一句话），只记进结果，生成只看图。
- 要多久：卸下主模型、加载生成模型、再装回主模型来回约 5 分钟另算；单图约 3 分钟。

结果：JSON（file 是 GLB，带 4096 贴图，几十 MB；preview 是 4 角度拼图；另有 views、mb、seed、seconds）和那张拼图。
